Technical Notes

  • Framework selection: VS Insiders v18 does not expose a "Target Framework" ComboBox in the toolbar for multi-targeted projects. The "Debug Target" SplitButton only shows launch profiles (project name, WSL, Debug Properties). Framework selection is implemented by rewriting the .csproj to single-target via write_text.py.
  • Run command: "Run All Tests In View" from the draft is replaced with Ctrl+F5 (Start Without Debugging) because console apps have no test project.
  • Console detection: VS Debug Console uses class CASCADIA_HOSTING_WINDOW_CLASS with title "Microsoft Visual Studio Debug Console".
  • File writes: Both Program.cs and .csproj are written directly to disk via write_text.py instead of keyboard input in the VS editor. This avoids XML mangling from type_text.py and ensures files persist after VS force-close.
  • Project naming: Auto-incremented names (ConsoleApp35, ConsoleApp36, etc.) avoid stale-folder UIA tree issues.
